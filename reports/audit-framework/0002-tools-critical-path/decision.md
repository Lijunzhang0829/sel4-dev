### check-theory.sh bug fixes
(`claude/.claude/skills/isabelle_prover/scripts-container/check-theory.sh`)

**B1: path traversal off-by-one.** Was `REPO_ROOT="$(cd
"${SCRIPT_DIR}/../../../../.." && pwd)"` (5 hops, old `claude/.claude/`
layout). Current layout is `<repo>/.claude/skills/isabelle_prover/
scripts-container/` (4 hops). Fixed to 4 hops. Before fix:
`$ISA_HOME` resolved to `//verification/isabelle` (root-rooted from
`REPO_ROOT="/"`) → `isabelle: No such file or directory` failure.

**B2: `xxd` not in container.** `TMPNAME` was generated by
`$(head -c8 /dev/urandom | xxd -p)` but the sel4-l4v container has no
xxd binary. Replaced with `$(python3 -c 'import secrets; print
(secrets.token_hex(8))')` — portable, no external dependency.
