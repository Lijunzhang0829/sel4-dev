# 首次人工语义审查

审查对象：首版 binary heap 的环境、表示关系和六个顶层目标。
状态：用户已于 2026-11-04（Asia/Shanghai）确认本文件的首版范围和目标，可以继续。确认绑定见 `review-approval.json`。这里仍是作者的解释，独立盲回译单独记录。

## 需要决定的三项

1. **首版使用范围**：顺序整数最小堆，使用上游 `int_compare`；有效 payload 由调用者拥有，键在操作期间保持不变，允许重复指针和重复键。任意比较器、最大堆和并发留到后续版本。
2. **外部环境边界**：接受显式的分配/释放契约作为假设，证明原始堆代码在该环境下的行为；本轮不证明具体 libc。允许失败、原地扩容与搬迁；释放后仅保留其他活块和调用者数据，不承诺死块字节不变。
3. **机器数值范围**：容量小于 `2^31`；需要扩容的插入还要求新容量小于 `2^31`。这个前提为 `pop` 中 `2*index+1/2` 的 32 位索引计算留下安全范围，边界扩容不会被暗中按数学自然数执行。

建议确认上述范围后，才冻结目标并准备正式生成适配。若修改范围，应更新定义与目标、重新做回译和原生预检，并建立新版本绑定；不能在运行中加强前提后沿用旧成绩。

## 六个目标实际要求

| 目标 | 前提与结论 |
|---|---|
| `bh_count_exact` | 对合法表示，返回值等于指针多重集大小，整个模型状态不变。 |
| `bh_insert_correct` | 合法堆、有效新 payload、扩容范围合法；成功只增加一次该指针，保持表示、调用者数据和其他活块，分配图只改变数组块；返回 0 时模型状态不变。 |
| `bh_insert_without_growth` | 计数小于容量时，插入不能失败；数组地址、容量及分配状态不变，修改限定在堆所有的存储中。 |
| `bh_pop_correct` | 空堆返回 NULL 并保持状态；非空时返回原多重集内键最小的指针，仅删除该指针的一次出现，保持表示；不改变分配状态、数组位置或容量。相同键之间不要求稳定顺序。 |
| `bh_free_owned_storage` | 删除恰好堆对象和数组的两条分配记录，保留调用者数据和这两个块之外的字节；释放后不再要求能解释该堆对象。 |
| `bh_new_empty_or_failure` | 对合法分配环境，成功返回容量 16 的合法空堆且恰好新增对象和数组两个活块；失败后活块记录恢复原状。两种情况都保护原有活块和调用者保留区。 |

所有目标都要求执行不发生语义失败，结果集合非空，且每个结果均满足结论。
只有某次尝试失败不能说明目标为假；正式证伪要在相同基础及 locale 下证明完整量化目标的否定。
